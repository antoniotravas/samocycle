## Samocycle -  Bike for all

## Objetivo

    Criação de um web site para divulgação de serviços relacionado com reparação de bicicletas e venda de material 
    A tecnologia a implementar será php e mysql no backend e html javascript e css front end
    Usa as skills de front end
    Site simples e de fácil leitura, sóbrio e com identidade semenhante à da página de facebook
    Possibilidade de venda online, mbway principalmente
